# RECLAIM Admin Console — testing

1. Upload all files from this package to the root of your existing GitHub repository, replacing the older files.
2. Open the RECLAIM website and sign in with the first local account (the account marked admin).
3. Add test craving logs and mood check-ins in the app. You can also add journal entries; the admin page will count them without showing their text.
4. Open the Admin console link in the left navigation, or visit `/admin.html`.
5. Press Refresh dashboard after adding entries.

The console aggregates locally stored records for accounts in this same browser profile. It does not connect to other people's devices. It intentionally hides journal text, notes, craving context and coping responses. Local browser roles and records are not tamper-proof; this is for testing, not secure public administration.


**Hidden shortcut:** Click the RECLAIM logo in the sidebar five times within three seconds to open the admin console. This is a convenience shortcut, not password security.
